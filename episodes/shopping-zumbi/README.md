# Shopping Zumbi — vídeo animado

Entrega do episódio produzido com a SKILL de sobrevivência ilustrada, usando a narração fornecida pelo usuário.

## Arquivos

- `output/shopping-zumbi-final.mp4` — vídeo final, 1280×720, 6min22s.
- `output/projeto-editavel.zip` — scripts, timeline, narração e documentação para reprodução.
- `output/contato-01.jpg` e `output/contato-02.jpg` — folhas de contato para revisão visual.
- `output/quadro-preview.png` — quadro de prévia.
- `output/storyboard.csv` — timeline dos planos.
- `output/producao.md` — registro da produção e validação.
