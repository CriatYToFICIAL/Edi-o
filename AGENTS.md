# Instruções para agentes neste projeto

Para analisar referências, planejar ou editar vídeos do canal, leia primeiro `.agents/skills/canal-caderno-narrativo/SKILL.md` e os arquivos em `references/` indicados por ela. Essa Skill define a linguagem editorial do canal; as Skills oficiais do HyperFrames orientam a implementação técnica.

Para escolher ou criar imagens, GIFs, ícones, documentos, diagramas ou motion sincronizados à narração, leia `.agents/skills/material-narrativo/SKILL.md` e seu modelo de plano. Essa etapa acontece antes da montagem da timeline.

As referências recebidas servem para extrair estrutura, ritmo e princípios visuais. Produza material original e mantenha um registro de origem e direitos dos ativos usados em vídeos finais.

O repositório já é o checkout de trabalho. Não crie outro worktree a menos que o usuário peça explicitamente.
